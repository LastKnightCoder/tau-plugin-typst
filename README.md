# Typst 排版

在文档里写 Typst，直接看到排版好的效果，适合写公式、表格和精细排版的内容。不用另外安装 Typst，排版结果还能发布到博客。

## 开始使用

1. 在插件中心安装「Typst 排版」，再到插件页的「已安装」里打开它的开关，然后点插件页顶部提示条上的「立即重启」，重启后就能用了。
2. 在文档的插入菜单里选择「Typst」。
3. 写好内容，排版成功后结果会随文档一起保存。

也可以让 AI 助手帮你写 Typst。

## 本地排版与离线使用

排版直接在 Tau 本地完成，不需要额外安装 Typst 程序。首次使用时会联网下载排版组件与默认字体（约 32 MiB），下载完成后会长期缓存在本机，之后离线也能正常排版。下载与排版进度会直接显示在 Typst 块里。

## 常见问题

**博客里显示的是代码，不是排版结果？** 博客展示的是你在 Tau 里最后一次排版成功并保存的结果。回到 Tau 编辑一下这个 Typst 块，让它重新排版，保存后再发布一次；只是打开看看不会更新博客用的结果。如果还是不行，把博客模板更新到最新后再重新发布。

**首次排版提示下载失败？** 检查网络后重试即可。下载源有主备两个，偶尔某个源不可用会自动换源，已下载的部分不需要重新下载。

**能导出 PDF 吗？** 不能。插件只负责在文档里预览排版效果，并将保存的结果展示在博客中。

**停用插件后内容会丢吗？** 不会。内容一直保存在文档里，重新启用后照常显示。

**手机上可以用吗？** 可以，在手机上安装并启用「Typst 排版」后同样可以编辑和预览。浏览器插件不渲染 Typst，但文档里的内容不会丢失。

## 小提醒

- 打开、关闭或升级这个插件后，都要重启 Tau 才会生效，插件页会提示「立即重启」。

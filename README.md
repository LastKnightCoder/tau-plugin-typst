# Typst 排版

在文档里写 Typst，直接看到排版好的效果，适合写公式、表格和精细排版的内容。不用另外安装 Typst。排版结果还能发布到博客。

## 开始使用

1. 在插件中心安装「Typst 排版」，装好后完全退出 Tau 再重新打开。
2. 在文档的插入菜单里选择「Typst」。
3. 写好内容，排版成功后结果会随文档一起保存。

也可以让 AI 助手帮你写 Typst。

## 常见问题

**博客里显示的是代码，不是排版结果？** 博客展示的是你在 Tau 里最后一次排版成功并保存的结果。回到 Tau 编辑一下这个 Typst 块，让它重新排版，保存后再发布一次；只是打开看看不会更新博客用的结果。如果还是不行，把博客模板更新到最新版本，再重新发布。

**能导出 PDF 吗？** 暂时不能。

**停用插件后内容会丢吗？** 不会。内容一直保存在文档里，重新启用后照常显示。

**手机上为什么看不到？** 手机版和浏览器插件暂时显示不了 Typst，但内容不会丢。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- 启用、停用或升级插件后，要完全退出 Tau 再打开才会生效。

# Typst 排版

在文件中撰寫 Typst，直接預覽排版後的效果，適合撰寫公式、表格與精細排版內容。不需另外安裝 Typst，排版結果也可發佈至部落格。

## 開始使用

1. 在外掛中心安裝「Typst 排版」，再到外掛頁的「已安裝」中開啟開關，接著點選外掛頁頂部提示列上的「立即重啟」，重新啟動後即可使用。
2. 在文件的插入選單中選擇「Typst」。
3. 完成內容撰寫並排版成功後，結果會隨文件一併儲存。

也可以請 AI 助手幫你撰寫 Typst。

## 本機排版與離線使用

排版直接在 Tau 本機完成，不需要額外安裝 Typst 程式。首次使用時會連線下載排版元件與預設字型（約 32 MiB），下載完成後會長期快取在本機，之後離線也能正常排版。下載與排版進度會直接顯示在 Typst 區塊中。

## 常見問題

**部落格顯示的是程式碼，而不是排版結果？** 部落格呈現的是你在 Tau 中最後一次排版成功並儲存的結果。回到 Tau 編輯一下這個 Typst 區塊，讓它重新排版、儲存後再發佈一次；單純開啟檢視不會更新部落格使用的結果。若仍無法顯示，請將部落格模板更新至最新後再重新發佈。

**首次排版提示下載失敗？** 檢查網路連線後重試即可。下載來源提供主備兩個節點，偶爾某個來源無法連線時會自動切換，已下載的部分不需重新下載。

**可以匯出 PDF 嗎？** 不能。外掛只負責在文件中預覽排版效果，並將儲存的結果展示於部落格中。

**停用外掛後內容會遺失嗎？** 不會。內容一直儲存在文件中，重新啟用後即可照常顯示。

**手機上可以用嗎？** 可以，在手機上安裝並啟用「Typst 排版」後同樣可以編輯與預覽。瀏覽器擴充功能不會顯示 Typst 排版結果，但文件中的內容不會遺失。

## 小提醒

- 開啟、關閉或升級此外掛後，都必須重新啟動 Tau 才會生效，外掛頁會顯示「立即重啟」提示。
